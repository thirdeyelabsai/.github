# ThirdEye Labs

We build open road data for autonomous driving in India.

Our first release, the [Indian Road Driving Dataset](https://huggingface.co/datasets/thirdeyelabs/indian-road-dataset), holds 645,714 annotated dashcam frames from Delhi NCR: 3.67M tracked 2D detections and 1.29M segmentation masks across 12 classes, in BDD100K format.
